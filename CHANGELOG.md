# Journal des modifications

Les changements notables de ce projet sont consignés dans ce fichier.

## [1.0.0] - Première version stable

- Bibliothèque statique C17 pour compter lignes, mots, octets et points de code UTF-8 d'un flux.
- API publique documentée et exécutable CLI de démonstration.
- Tests unitaires, fonctionnels et d'intégration, avec couverture gcov à 100 % des lignes et branches du code de production.
- CI avec GCC, Clang, AddressSanitizer et UndefinedBehaviorSanitizer.
- Installation de l'archive, de l'en-tête et des métadonnées `pkg-config`.
